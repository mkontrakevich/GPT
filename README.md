# ЦУМ Нижний Новгород — Animated Editorial Site

Рабочая версия на базе визуально сильной v2-композиции: крупные изображения, спокойный ритм, анимация, знакомая навигация текущего csum.ru и новый редакционный слой.

## Внутри
- `index.html` — основная анимированная страница.
- `magazine.html` — журнал ЦУМа.
- `articles/` — 9 полноценных журнальных материалов с нативными ссылками на арендаторов.
- `skills/csum-editorial-writer/SKILL.md` — редакционный skill для генерации новых материалов в том же стандарте.
- `.github/copilot-instructions.md` — инструкция для AI-редакторов репозитория.
- `CONTENT_PLAN.md` — очередь следующих материалов.
- `.github/workflows/pages.yml` — GitHub Pages deployment workflow для отдельного репозитория.

## Редакционный принцип
Сначала читатель получает полезный материал: историю, объяснение, городской сценарий или обзор. Магазин и товар появляются только там, где естественно продолжают уже сформированную потребность. Лобовая реклама внутри статей запрещена.

## Мягкая миграция с csum.ru
Сохранены знакомые точки входа: О ЦУМе, Магазины, Еда, Развлечения, Новости и акции, Афиша, Контакты. Новый журнал работает поверх привычной структуры, а ссылки на актуальные карточки магазинов ведут на действующий csum.ru.

## Визуальная логика
- реальный ЦУМ — на главном hero;
- крупные самостоятельные фото-сцены, а не изображения интерфейсных макетов;
- архитектурные изображения — с выправленными вертикалями;
- controlled motion: reveal, sticky editorial nav, hero parallax, сценарии и карта;
- 4K/ARCH LOCK pipeline: сохранение идентичности и геометрии → controlled correction → high-quality upscale → detail restore.

## Локальный запуск
```bash
python -m http.server 8080
```
Открыть `http://localhost:8080/`.
## v4 — встроенный генератор изображений
- `admin.html` — встроенный CSUM Image Studio.
- `content/visuals.json` — единый каталог визуалов секций и статей.
- `openrouter-image.js` — browser client без API-ключа.
- `site-image-runtime.js` — подмена опубликованных изображений на главной, в журнале и статьях.
- `workers/csum-image-api/` — Cloudflare Worker-прокси к OpenRouter Image API.
- `editor-image-studio.js` — генерация, preview и публикация выбранного candidate.

OpenRouter key хранится только в Worker secret. В production-режиме R2 хранит generated assets и активный JSON-manifest изображений. Публичный сайт получает только опубликованный manifest.

Открыть редактор локально: `/admin.html`.
