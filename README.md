# ЦУМ Нижний Новгород — Animated Editorial Site

Актуальная анимированная версия на базе визуально сильной v2-композиции.

## Состав
- `index.html` — анимированная главная.
- `magazine.html` — редакционная витрина.
- `articles.html` — 9 готовых журнальных статей с нативными интеграциями.
- `skills/csum-editorial-writer/SKILL.md` — skill для генерации новых материалов в том же стандарте.

## Принцип
Сначала полезная история, городской сценарий или обзор. Товар и арендатор появляются только в естественной точке материала.

## Мягкая миграция
Сохранены привычные входы действующего csum.ru: О ЦУМе, Магазины, Еда, Развлечения, Новости и акции, Афиша, Контакты.
