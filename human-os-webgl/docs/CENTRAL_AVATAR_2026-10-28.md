## Центральное размещение

Один экземпляр модели постоянно находится на центральном постаменте [0, 0.20, 0]. Выбор острова меняет контекст одежды, но не переносит героя на остров. Возврат к общей карте сохраняет героя видимым. ## Создание модели по фото

Пользователь предоставил многоракурсный коллаж. Исходник и описание индивидуальных особенностей не публикуются в репозитории и Workers. Коллаж пригоден для визуального моделирования лица и одетого силуэта. Неизвестные участки, вид сзади и анатомия под одеждой не могут считаться восстановленными по измерениям. Нельзя обещать точное фотографическое сходство по одному коллажу или объявлять реконструкцию готовой.

Доступный инструментарий проверен: подключённого генератора image-to-3D не найдено. Meshy документирует создание GLB из отдельных ракурсов, но требует авторизации API и оплачиваемого доступа: https://docs.meshy.ai/en/api/multi-image-to-3d . Фото не передавалось внешнему генератору, платный запуск не выполнялся. Текущая модель остаётся процедурной. Растровое изображение не выдаётся за 3D-модель.

Для производственного результата нужны отдельные ракурсы → модель головы и тела → проверка сходства спереди/сбоку/три четверти → отдельная одежда → скелет и деформации параметров → оптимизация GLB и проверка WebGL. Для купального вида под одеждой нужна дополнительная информация о форме тела; по футболке и брюкам её не выдумываем как достоверную.
