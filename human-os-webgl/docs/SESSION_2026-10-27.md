## Implementation
- Six original reusable glTF signature meshes with bounded payloads and PBR factors: sanctuary ribs, branching tree skeleton, crystal armillary, observation spire, garden pergola, layered open-book pages.
- These are additive parametric assets, not claims of a finished externally authored cinematic asset library. Existing six landmarks, terrain, palette, lighting and bridges remain.
- Static opaque geometry is combined per island/material/attribute layout; picking, animated objects, transparent effects and GPU instancing stay independent.
- Shared material cache avoids repeated identical bookshelf materials.
- Camera orbits its actual focus target; transitions use elapsed time.
- Unified pointer gestures avoid simultaneous touch zoom and orbit; cancellation clears gestures.
- Resize updates DPR/FOV and overview distance; reduced-motion preference is honored.
- Context loss pauses rendering, preserves navigation, restores renderer and exposes recovery counters.
- Read-only diagnostics expose frame-time percentiles, actual render calls/triangles, geometry/texture counts, camera and load errors. Browser FPS must not be presented as physical iPhone performance.
