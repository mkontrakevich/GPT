# Personal Sign — политика конфиденциальности

Версия: 1.6

## 1. Назначение
Personal Sign — локальный браузерный инструмент для открытия PDF/DOC/DOCX, размещения графического росчерка и формирования PDF с контрольным файлом .psig.

## 2. Содержимое документов
Архитектура приложения не предусматривает серверный API для загрузки документов автору приложения. Содержимое выбранного пользователем документа, точки рукописного ввода, отдельное изображение подписи и PIN/пароль Vault кодом приложения автору не отправляются.

## 3. Что хранится на устройстве
В зависимости от действий пользователя в браузере могут храниться:
- настройки пера;
- non-extractable ключ ECDSA для .psig;
- параметры защиты Vault;
- зашифрованные записи Vault, только если пользователь явно сохранил документ;
- локальный PWA-кэш.

## 4. Vault
Vault использует AES-256-GCM. Ключ выводится из PIN/пароля пользователя через PBKDF2-HMAC-SHA-256 и во время разблокировки находится только в оперативной памяти. PIN/пароль не сохраняется.

## 5. Приватная сессия
Исходный документ и отдельный рисунок подписи не сохраняются автоматически. После формирования итогового PDF рабочие данные очищаются из состояния приложения.

## 6. Технические сетевые данные
Текущая веб-версия загружается через хостинг и при первом запуске использует внешние библиотеки. Соответствующие провайдеры могут получать технические данные сетевого соединения, включая IP-адрес, время запроса и User-Agent. Код Personal Sign не передает им содержимое выбранных документов.

## 7. Данные третьих лиц
Пользователь самостоятельно определяет наличие законного основания для работы с персональными данными третьих лиц, содержащимися в выбранном им документе.

## 8. Очистка
В приложении доступна функция удаления локального Vault, ключей, настроек и PWA-кэша. Очистка данных браузера или удаление приложения также может удалить локальные ключи и сделать Vault недоступным.

## 9. Изменение архитектуры
Добавление аккаунтов, серверного API, аналитики, журналирования содержимого, облачного Vault, отправки документов или иных функций обработки персональных данных требует отдельной правовой и технической оценки до публикации.
